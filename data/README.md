# Data Directory

This directory contains synthetic aerospace procurement datasets used by the Aerospace Supplier Intelligence Platform.

## Planned Datasets

- Supplier Master
- Purchase Orders
- Delivery Records
- Supplier Performance
- Procurement Spend
- Inventory Records
- Supplier Risk Indicators

## Data Governance

- Synthetic demonstration data only.
- No confidential company or supplier information.
- No proprietary aerospace procurement records.
- Data must be validated before use in dashboards or AI analysis.
